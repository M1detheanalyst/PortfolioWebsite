# Joshua Bakare Portfolio Website

Complete current website export.

## Files
- index.html: every section, component, portfolio description, credential, and contact link.
- styles.css: all styles and responsive layouts.
- script.js: navigation, scroll color changes, reveal effects, and project expansion.
- assets/: local images.
- external-dependencies.json: any image references that could not be downloaded.

## Run
Open index.html in your browser, or serve this folder with `python3 -m http.server 8000` and visit http://localhost:8000.

## Technology
HTML5, CSS3, JavaScript, and inline SVG icons. No framework, backend, database, package installation, or build step is required. All portfolio content is in index.html.

Google Fonts are loaded online (Fraunces, Inter Tight, JetBrains Mono). GitHub, social, email, phone and WhatsApp links require their usual external applications or services. The CV button requests the CV by email; no CV file was supplied. Dashboard thumbnails are image previews, not live dashboard datasets. No credentials, private hosting tokens, Git history, or unrelated uploads are included.
